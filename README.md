# SJKC KBA Graduation Ceremony 2026

Official graduation booklet: 下一幕，出发 · 第七十四届毕业典礼.

Static nine-page booklet. Open `index.html` through an HTTP server, or publish this directory with GitHub Pages from the main branch root. All page artwork and audio are bundled locally. No build or tracking service is required.

Music: **In Your Arms** by Kevin MacLeod, [incompetech.com](https://incompetech.com/), licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). Original recording, unchanged. The music button also exposes this credit on long press or right click. Browser rules may require the first tap before audio starts.

Page-turn library: StPageFlip, MIT; see `assets/page-flip.LICENSE`. Local modifications provide mobile Canvas rendering and matched forward/backward animation timing.
